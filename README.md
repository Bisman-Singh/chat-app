# Chat App

A real-time chat UI with simulated WebSocket-style messaging, built with React.

## Features

- Multiple chat rooms: General, Tech, Random
- Message list with timestamps
- Typing indicator
- User avatars (colored circles with initials)
- Online user list sidebar
- Emoji picker (24 common emojis)
- Simulated bot responses (1-3 random messages after each user message)
- 5 bot users with different names and avatar colors
- Dark theme with blue accent

## Tech Stack

- React 19 + Vite
- Component state (no external state management)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
```
